# Three int4 calibration files added 2026-08-17, and what each is NOT

The shipped `int4_calibration_realckpt.pt` is **unchanged**. Adopting any file below means re-measuring
every committed W4A4 number, which is why none of them replaces it.

## Why they exist

`ACT_CLIP_RATIO = 4.5` is applied ONCE, in `end_calibration`
([int4_optimized.py:1761](../kernels/int4_optimized.py:1761)), and baked into whatever
`export_int4_static_scales` writes. The load path only fills the value (`set_static_scale`, :1892). So a
file exported before the constant landed carries no 4.5 — and `int4_calibration_realckpt.pt` is dated
**2026-08-04** against the constant's **08-12**. Matching it against fresh calibrations at both settings:
it matches ratio **1.0 (0.9398)**, not 4.5 (**4.3022**). See docs/OPEN_ITEMS.md A22.

| file | `ACT_CLIP_RATIO` | attention score path | `MODIFF_LINEAR` | measured |
|---|---|---|---|---|
| `int4_calibration_realckpt.pt` *(shipped, untouched)* | **1.0** (by vintage, not by choice) | quantized | 0 | every committed W4A4 number |
| `int4_calibration_clip1.0.pt` | 1.0 | quantized | 0 | FID **55.424** — the control, reproduces the shipped arm |
| `int4_calibration_clip4.5.pt` | **4.5** | quantized | 0 | FID **54.300** — best W4A4 as of 2026-08-17 |
| `int4_calibration_attnfp16.pt` | **4.5** | **fp16** | **1** | **not measured — see the warning** |

## The warning on `int4_calibration_attnfp16.pt`

It was produced while testing whether the fp16 attention score path helps, before the `ACT_CLIP_RATIO`
problem above was understood. It therefore differs from the shipped file on **three** axes at once —
clip ratio, attention, and `MODIFF_LINEAR` — so a run using it measures none of them.

It is kept rather than deleted because it is a valid fp16-attention calibration and the axis is worth
testing. But testing it needs a **matched pair**: two fresh calibrations differing ONLY in
`MODIFF_QUANT_ATTN`, with the same clip ratio and the same `MODIFF_LINEAR`. Neither of the files above is
that partner. Regenerate both with
[`calibrate_attnfp16.py`](../../docs/w4a4_quality_2026-08-17/scripts/calibrate_attnfp16.py) and its
attention-on twin before quoting anything from this axis.

**The axis is currently UNTESTED, not refuted.** The one measurement of it (+4.1% on a 16-image screen)
is invalid twice over: the screen's cross-process floor is 8.7/255 (OPEN_ITEMS A19), and the scales it
loaded were mismatched to its configuration by 4.3×.
