# a_hat / o_hat conv-block ablation, W8A8 vs W4A4, all 20 real conv shapes

Methodology: independent-layers chained (no same-buffer RAW hazard), 5 independent trials per
shape with alternating measurement order (cancels systematic drift between arms), 16 layers/chain,
40 chain reps/trial. Matched to the actual production kernels:

- GN base / MoDiff: `group_norm_silu_quantize_nhwc_fast` vs `group_norm_silu_delta_quantize_nhwc`
  (W8A8) / `group_norm_silu_quantize_pack_nhwc_fast` vs `group_norm_silu_delta_quantize_pack_nhwc` (W4A4)
- conv base / MoDiff: `conv2d_int{8,4}_evt_bias_residual_fp16` vs `conv2d_int{8,4}_evt_o_hat`

`a_hat` = GN step delta (MoDiff GN - baseline GN). `o_hat` = conv step delta (MoDiff conv -
baseline conv). Percentages are each cost as a share of MoDiff's own total (GN+conv) time.
`block ratio` = MoDiff total / baseline total (GN+conv both arms).
