Proj-side quantize fusion (quantize_attn_out_int8) — churches UNet, int8, A40, batch 64
=========================================================================================
Kernel: fuses the mandatory attn-output transpose(1,2)+reshape layout copy AND the int8
proj Linear's separate quantize pass into ONE gather+quantize -> int8 [b*T,C], fed to
gemm_w8a8_awq directly. Gated MODIFF_FUSE_PROJ_QUANT (default on); engages only for a
calibrated non-modiff W8A8 proj (21/21 attention blocks eligible).

CORRECTNESS
  Isolated kernel: bit-exact vs quantize_act_int8(a.transpose(1,2).reshape(b,T,C)), maxdiff=0 (4 shapes).
  Real proj layers: fused vs unfused proj output max|Δ|=0 (bit-exact) on captured activations.
  Whole UNet forward: OFF-vs-ON rel-L2 ~4e-2, within the int8 kernels' OFF-vs-OFF nondeterminism floor (~2.8e-2).

READ: correct, in-tree, removes ~0.53 ms/step of real work at the proj stage, but e2e is within
noise because proj input-prep is ~0.5% of this conv-bound step (Amdahl). The matching qkv-side
quantize (~0.64 ms/step) is the other half; fusing both is ~1.2% e2e at most.


=========================================================================================
QKV-SIDE quantize fusion (group_norm_silu_quantize_nhwc) — the other half
=========================================================================================
Folds the int8 qkv Linear's quantize pass into the GroupNorm producer: the attention GN
(no SiLU) is computed in fp32 and emitted as int8 [b*T,C] directly (a free channels_last
token-major view), fed to gemm_w8a8_awq. Reuses the existing conv-path GN-quantize kernel
(no new CUDA). Gated MODIFF_FUSE_QKV_QUANT (default on); 21/21 qkv blocks eligible.
NOTE: in the real int8 model _fuse_gn_qkv is OFF, so all 21 qkv layers run int8 (verified).

CORRECTNESS (fused vs native-GN-fp16 + quantize_act_int8 + gemm, real activations)
  rel-L2 ~2e-3 per block (one fp16-rounding difference: fused quantizes off fp32 GN). Whole
  UNet OFF-vs-ON rel-L2 4.5e-2, within the OFF-vs-OFF nondeterminism floor (2.9e-2).

READ: both halves of the Linear-quantize tax are now fused away, correctly, in-tree. Combined
